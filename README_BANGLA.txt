জামিয়াতুল আবরার ক্যাশ স্টেটমেন্ট — লাইভ ওয়েবসাইট ও APK অ্যাপ তৈরির গাইড
========================================================================

এই প্যাকেজের ভেতর আপনার পূর্ণাঙ্গ ওয়েব অ্যাপ এবং আলাদা Android (.apk) অ্যাপ 
তৈরির সব ফাইল দেওয়া আছে:
1. index.html         -> আপনার সবুজ ডিজাইনের ৩-বক্স অ্যাপ ও অ্যাডমিন প্যানেল
2. manifest.json      -> মোবাইল অ্যাপের নাম, রঙ ও আইকন কনফিগারেশন
3. service-worker.js  -> অফলাইন ও আলাদা APK অ্যাপ সাপোর্ট
4. icons/             -> অ্যাপের ১৯২x১৯২ এবং ৫১২x৫১২ সবুজ আইকন
5. Code.gs            -> আপনার গুগল শিটের সাথে লাইভ কানেকশনের কোড

------------------------------------------------------------------------
ধাপ ১: Netlify-তে ওয়েবসাইট হিসেবে লাইভ পাবলিশ করা (সময়: ১ মিনিট)
------------------------------------------------------------------------
১. প্রথমে এই .zip ফাইলটি আপনার কম্পিউটার বা মোবাইলে Unzip (Extract) করুন।
   (ফোল্ডারের ভেতর থেকে শুধু `Code.gs` ও `README_BANGLA.txt` চাইলে আলাদা সরিয়ে 
   রাখতে পারেন, অথবা পুরো ফোল্ডার রাখলেও কোনো সমস্যা নেই)।
২. ব্রাউজারে যান: https://app.netlify.com/drop
৩. ফোল্ডারটি ড্র্যাগ করে ছেড়ে দিন (Drag & Drop)।
৪. কয়েক সেকেন্ডের মধ্যেই আপনি একটি লাইভ ওয়েবসাইট লিংক (https://....netlify.app) 
   পেয়ে যাবেন! এটিই আপনার কম্পিউটার ও ব্রাউজার ওয়েব অ্যাপ।

------------------------------------------------------------------------
ধাপ ২: PWABuilder দিয়ে আলাদা Android (.apk) অ্যাপ বানানো
------------------------------------------------------------------------
১. ব্রাউজারে যান: https://www.pwabuilder.com/
২. উপরের বক্সে আপনার Netlify থেকে পাওয়া লাইভ লিংকটি পেস্ট করে "Start" দিন।
৩. এরপর "Package For Stores" -> "Android" সিলেক্ট করে ডাউনলোড করুন।
৪. ডাউনলোড হওয়া ফাইলের ভেতরেই আপনার .apk ফাইল থাকবে! সেটি মোবাইলে ইনস্টল 
   করলে Google Docs বা Sheets-এর মতোই আলাদা অ্যাপ হিসেবে চলবে।

------------------------------------------------------------------------
ধাপ ৩: গুগল শিটের সাথে লাইভ কানেক্ট করা (ওয়েব ও অ্যাপ অটো-সিঙ্ক)
------------------------------------------------------------------------
১. আপনার গুগল শিট (Nobember-2026 বা Blane) খুলুন।
২. উপরের মেনু থেকে Extensions -> Apps Script-এ ক্লিক করুন।
৩. সেখানে থাকা কোড মুছে এই প্যাকেজের `Code.gs` ফাইলের সম্পূর্ণ কোড পেস্ট করুন।
৪. Save করে ডানদিকের Deploy -> New deployment -> Web app সিলেক্ট করুন।
   - Execute as: Me
   - Who has access: Anyone
   তারপর Deploy বাটনে ক্লিক করে পাওয়া Web App URL-টি কপি করুন।
৫. এবার আপনার লাইভ ওয়েব অ্যাপ বা APK অ্যাপে লগইন করে (ডিফল্ট আইডি: admin, 
   পিন: 1234) "🔐 অ্যাডমিন প্যানেল ও নিয়ম" ট্যাবে যান।
৬. সেখানে "গুগল শিট লাইভ সিঙ্ক URL" ঘরে ওই লিংকটি বসিয়ে সেভ করুন এবং 
   "🔄 শিট থেকে আনুন" বা "☁️ শিটে পাঠান" বাটনে ক্লিক করুন!
